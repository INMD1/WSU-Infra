# 2025-05-08 — Claude 디자인 시스템 전체 적용

## 이번 작업에서 무엇을 했나요?

WSU 클라우드 포털의 UI 전체를 **Claude(Anthropic) 디자인 시스템**으로 통일했습니다.  
이전에는 Google Cloud Platform(GCP) 스타일의 클래스가 컴포넌트 곳곳에 섞여 있었고,  
CSS 변수 충돌로 인해 색상이 제대로 적용되지 않는 버그도 있었습니다.

---

## 왜 바꿨나요?

- `DESIGN.md`에 Claude 브랜드 디자인 스펙이 정의되어 있었지만, 실제 컴포넌트는 GCP 스타일(파란 버튼, 회색 배경)을 쓰고 있었음
- `globals.css`에 두 번째 `:root` 블록이 있어서 첫 번째 Claude 색상 토큰을 shadcn 기본값(oklch 회색 계열)으로 덮어쓰고 있었음  
  → 결과적으로 `bg-primary`가 코랄(#cc785c)이 아니라 거의 검정에 가까운 색으로 나왔음

---

## 무엇이 바뀌었나요?

### 1. `globals.css` — CSS의 핵심 기반 수정

**문제**: 파일 안에 `:root { }` 블록이 두 개 있었고, 뒤쪽 블록이 앞쪽 클로드 색상을 덮어썼음

```css
/* 첫 번째 :root (Claude 토큰) */
:root { --primary: #cc785c; ... }

/* 두 번째 :root (shadcn 기본값이 덮어씀! ← 버그) */
:root { --primary: oklch(0.205 0 0); ... }
```

**해결**: `:root`를 하나로 통합하고, Claude 값으로 shadcn 토큰도 함께 설정

추가 변경사항:
- GCP 전용 클래스 전부 제거 (`.card-gcp`, `.btn-gcp-*`, `.table-gcp`, `.progress-gcp-*`, `.badge-gcp`, `.status-*-gcp`)
- Claude용 클래스 추가: `.alert-error`, `.alert-success`, `.alert-warning`, `.status-badge`, `.status-running` 등
- `.dark {}` 블록을 Claude 다크 테마 값으로 교체
- `@theme inline`의 `--font-heading`을 `var(--font-display)` (serif)로 수정

---

### 2. `layout.tsx` — 폰트 정리

**이전**: Geist + Inter 두 가지를 동시에 로드 (충돌 가능성)  
**이후**: Inter만 Next.js 최적화 폰트로 로드, Cormorant Garamond는 globals.css의 Google Fonts import로 처리

## 디자인 시스템 요약 (앞으로 이걸 기준으로 쓰세요)

### 색상 토큰 (Tailwind 유틸리티로 쓰면 됩니다)

```
배경:    bg-canvas          → #faf9f5 (따뜻한 크림색)
카드:    bg-surface-card    → #efe9de (살짝 어두운 크림)
구분선:  border-hairline    → #e6dfd8
텍스트:  text-ink           → #141413 (거의 검정)
보조색:  text-muted         → #6c6a64 (회색)
강조:    bg-primary         → #cc785c (코랄, Anthropic 브랜드 색)
다크:    bg-surface-dark    → #181715 (코드 에디터 배경)
```

### 버튼 클래스

```tsx
<button className="btn-primary">주요 액션 (코랄 배경)</button>
<button className="btn-secondary">보조 액션 (테두리만)</button>
<button className="btn-ghost">텍스트형 버튼 (투명 배경)</button>
```

### 상태 배지

```tsx
<span className="status-badge status-running">running</span>
<span className="status-badge status-stopped">stopped</span>
<span className="status-badge status-pending">creating</span>
<span className="status-badge status-error">error</span>
```

### 알림 박스

```tsx
<div className="alert-error">오류 메시지</div>
<div className="alert-success">성공 메시지</div>
<div className="alert-warning">경고 메시지</div>
```

### 헤딩 (Cormorant Garamond serif)

```tsx
<h1 className="display-xl">홈페이지 대형 타이틀</h1>
<h2 className="display-md">섹션 제목</h2>
<h3 className="title-lg">카드 제목</h3>
```
